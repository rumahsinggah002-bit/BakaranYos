BAKARAN MAS BIOS - APLIKASI PENJUALAN OFFLINE

CARA MENJALANKAN DI HP ANDROID:
1. Ekstrak ZIP ini.
2. Upload SEMUA isi folder (index.html, style.css, app.js, manifest.json, sw.js, qris.jpg) ke repository GitHub. Letakkan langsung di bagian utama/root repository, jangan hanya upload file ZIP.
3. Di GitHub buka Settings > Pages.
4. Pada Build and deployment pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu proses selesai. Buka alamat GitHub Pages yang diberikan.
7. Di Chrome Android tekan menu titik tiga > Tambahkan ke layar utama / Install app.

FITUR:
- Catat pemasukan dan pengeluaran.
- Menu cepat Teh, Kopi, Bakaran.
- Harga Bakaran bisa dimasukkan saat penjualan.
- Tambah produk sendiri.
- Riwayat transaksi dan hapus transaksi.
- QRIS ditampilkan dari gambar qris.jpg.
- Data disimpan lokal di browser/perangkat.
- Service worker membantu aplikasi dibuka offline setelah pertama kali berhasil dimuat.

CATATAN:
- Aplikasi ini mencatat transaksi, bukan memverifikasi pembayaran QRIS secara otomatis.
- Pastikan nama merchant pada QRIS benar sebelum digunakan.
- Data tersimpan di browser HP yang digunakan. Jangan hapus data situs/browser jika ingin mempertahankan catatan.
